# 02 AgentRuntime 独立QA任务

本任务由主Agent在02执行交付审核后，通过Bridge投递给既有测试会话。测试对象为当前共享工作区，冻结设计仍为D02，开发自测与独立QA分别记录。

## 依据与职责

阅读适用AGENTS.md、README、02整阶段执行任务、D02完整设计及第11.2节、02开发交付报告和本轮主Agent协调记录。既有补充实施规划只供理解实现选择。旧待冻结文字以最新用户授权为准。

独立审查当前真实实现，运行必要功能、边界、异常、并发和生命周期验证。测试会话负责发现与复现问题，业务修复由主Agent裁决后交修复会话。保留所有现有工作区修改，测试性复现脚本使用临时目录，明确命令和调用入口。使用项目.venv及现有依赖，真实库验证只限已核实的专用测试库，沿用既有隔离、回滚及精确清理。模型使用可控替身。

## 必须核对的可观察行为

| 验收项 | 独立证据要求 |
| --- | --- |
| 两类澄清及Task生命周期 | 通用到具体保持Task并换Run，具体缺参保留目标，合法new_task及累计预算正确 |
| 路由与三骨架 | 非法模型输出有限纠正，取消明确不可用，三个真实编译骨架返回capability_unavailable |
| 父子隔离和公开消息 | 核验当前owner/task/run/Agent组合，私有消息不外泄，模型只看本任务允许范围 |
| 预算和普通结算 | 失败/重试/纠正均累计，主动时间跨Run继承，run_finish图内结算，END后无第二次常规写回 |
| 受理和互斥 | 同thread立即冲突，不同thread并发，8活动上限，受理前取消清理和受理后独立执行 |
| request_id | 同指纹复用原Run且不重执，异指纹冲突，有界保留与索引清理正确 |
| HTTP与订阅生命周期 | 响应构造/头失败、生成器首迭代前退出、消费中断开均释放原订阅，任务继续且新订阅可用 |
| 实际连接断开 | 至少一次真实本机socket断开与随后结果查询证据，说明阻塞点和取消发生时机 |
| 慢队列和晚清理 | 队列溢出唤醒消费方且执行继续，旧owner清理不删除新订阅 |
| 重订阅与公共协议 | 当前快照加未来事件，终态快照及一次done，非空Last-Event-ID拒绝，安全字段及来源投影 |
| 故障与uncertain | 快照/终结写入失败、超时和异常保留安全状态及可确定用量，unknown不归零，阻塞不随TTL清除 |
| 关闭和环境隔离 | shutdown有界且等待取消收敛，资源关闭顺序正确，跨用户及conversation统一404，production禁用 |

逐项记录实际用例、命令和结果。缺少证据标明未验证，不能用开发报告或测试数量代替观察。关注正常入口是否确实走新实现，以及测试替身是否绕过了被验收逻辑。

P3-01为01既有Ruff遗留。区分本阶段新增或触及的代码问题、原遗留、环境问题及后续03～05能力。真实HITL/PG Checkpointer重启、业务副作用、RAG和Store仍按后续阶段验收。

## 交付

报告保存为docs/question/02-agent-runtime-qa-report.md。包含整体PASS/PARTIAL/FAIL判断、D02矩阵证据、实际测试命令及独立用例结果、专用测试库和清理情况、代码检查范围及遗留归属。

每个问题给出稳定编号、P0～P3等级、设计依据、具体代码位置、复现步骤/输入、预期与实际行为、影响范围、修复建议和测试证据。疑似设计冲突与确定缺陷分别列出，主Agent逐项裁决。无法复现的推测明确标注。

完成后回复报告路径及问题摘要，阶段正式验收由主Agent完成。保持测试独立性，避免自行修复被测业务实现、改冻结设计、调用其他会话、执行Git归档或推进下一阶段。
