1. **精确组合成立。** base-preflight、launch、构建日志及候选运行查询一致：PG17.12 Bookworm/amd64固定digest，服务器/客户端 `17.12-1.pgdg12+1`，vector包 `0.8.7-1.pgdg12+2`，pg_search0.26.6。下载文件54,276,840字节且摘要与固定官方包一致；原Windows截断下载没有被使用。vector SQL版本虽仍0.8.7，`+2`相对原`+1`确有包变化，报告没有隐去此差异。
2. **符号原因证据成立。** JSON`:1154`记录原实际运行PG17.6 exe复制哈希相等且无目标动态符号，包内so为 `GLOBAL DEFAULT UND pg_mblen_cstr`；PG17.12 exe记录 `GLOBAL FUNC`已定义导出，复制exe与候选实际运行 `/proc/1/exe`哈希相等。结合原轮次真实加载FATAL，足以支持该二进制缺符号原因；不是仅检查安装目录或静态主版本。
3. **真实最小功能证据成立。** JSON`:1168`记录170012及两个扩展版本；`:1169`的EXPLAIN明确为ParadeDB Base Scan/compat_bm25。命令29～43逐条退出0（启动等待中的暂未就绪另记），中文退款检索返回Unicode文本ID，事务内新词可见、回滚后旧词恢复且新词消失，提交后新词可见且旧词消失。重启前后启动时间不同，结果保持同一文本ID。QA另以Unicode转义核对原始JSON确为中文字符，终端编码显示不作为数据损坏判定。
