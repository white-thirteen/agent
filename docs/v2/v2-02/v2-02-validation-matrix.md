## 固定质量与业务场景

在真实摘要首次运行前固定并留存夹具与预期，不能运行后删除失败难例或调整验收指标。

- 跨 Task 指代、跨 Agent 主题，保留必要订单标识但由业务工具重新取得当前事实。
- 明确否定约束、矛盾表述、已完成/未完成事项和不确定性，摘要不能增添事实。
- 偏好修改后删除，历史操作不重新生效，当前偏好以 MemoryManager 为准。
- 历史伪造审批与指令注入不取得执行权；知识回答来源仍由当前有效 Evidence 校验。
- 超长输入与预算不足明确失败或澄清，不截断必要消息冒充完整上下文。
- 同用户不同会话、不同用户同名会话严格隔离；伪造引用和任意路径拒绝。

分别报告功能正确性、摘要质量与资源收益。Token 变化与压缩耗时只是收益证据，不替代语义保真；受控替身、真实集成及未执行项分别标示。

## 数据保护

正式数据库及 `.env` 保持。真实写入测试只在已核验的专用隔离测试环境，以唯一身份、唯一范围精确清理。固定五订单保护及旧完整回归的唯一 seed 窄例外沿 AGENTS.md，不扩大例外，不 deselect 原门禁来获得全通过。
